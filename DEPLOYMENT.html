What You Need

1. GitHub Repository

cd D:\Nexus
git remote add origin https://github.com/YOUR_USERNAME/nexus-ai-command-center.git
git push -u origin master

2. Vercel Account

  • Go to vercel.com → Import GitHub repo
  • Framework: Next.js (auto-detected)
  • Add environment variables (see below)
  • Deploy

3. MongoDB Atlas (Free)

  • Go to mongodb.com/atlas
  • Create FREE M0 cluster
  • Create database user + password
  • Network Access → IP: 0.0.0.0/0
  • Connect → Drivers → Copy connection string

4. Vercel Environment Variables

VariableValue
MONGO_URLYour MongoDB Atlas string
DB_NAMEnexus
APP_SECRETRandom 32+ char string
ADMIN_USERNAMEYour username
ADMIN_PASSWORDYour password

5. GitHub Secrets (for 24/7 automation)

Repo → Settings → Secrets → Actions:

SecretValue
APP_URLhttps://your-app.vercel.app
NEXUS_API_TOKENJWT from /api/auth/login
NEXUS_CRON_TOKENSame as APP_SECRET
DISCORD_WEBHOOKDiscord webhook URL

Optional Integrations

Discord (approval cards)

  1. discord.com/developers/applications → New App → Bot
  2. OAuth2 → invite to server
  3. Channel → Webhook → copy URL
  4. Add to Integrations UI

LinkedIn (actual posting)

  1. linkedin.com/developers/apps → Create
  2. Add "Share on LinkedIn" + "Sign In"
  3. Get Client ID + Secret → add to Integrations

Meta/Facebook/Instagram

  1. developers.facebook.com → Create App
  2. Add Facebook Login + Instagram
  3. Get App ID + Secret → add to Integrations

Resend (email)

  1. resend.com → API Key
  2. Verify domain
  3. Add to Integrations
